# 테스트 결과

Windows, Python 3.12.14, Streamlit 1.67.0, pytest 8.4.2에서 새 가상 환경에 `requirements.txt`를 설치하고 `python -m pytest -q`를 실행했다.

## 자동 검증

**16개 통과.**

| 요구 시나리오 | 검증한 결과 |
|---|---|
| 1. 진단평가 | 10문항 처리, 개념별 정오답 집계, 취약 개념 선택 |
| 2. 정답 후 진행 | 다음 연습 위치 증가, 다른 연습문항 선택 |
| 3. 오답 후 힌트 | 정답을 공개하지 않는 힌트, 같은 문제 유지 |
| 4. 반복 오답 | 분수 뺄셈에서 선수 개념인 통분으로 이동 |
| 5. 학생별 저장 | 다른 학습 코드로는 기존 풀이 조회 불가 |
| 6. 기록 복원 | SQLite를 다시 열고 별도 Streamlit 세션에서 복원 |
| 7. 검색 실패 | 읽을 수 없는 자료만 있으면 안내와 기본 힌트 표시 |
| 8. API 연결 실패 | 연결 오류 후 기본 힌트와 근거 제공 |
| 9. Agent 도구 로그 | 조건부 Python 도구 호출과 6개 로그 단계 확인 |
| 10. 잘못된 모델 응답 | 잘못된 JSON과 허위 근거 ID를 각각 검증하고 한 번 수정 요청한 뒤 기본 모드 사용 |

추가로 약분·통분·정수 문항의 입력 형식, 중복 제출 방지, PDF 페이지 출처, localhost HTTP를 통한 Chat Completions 도구 요청·응답 교환을 검증했다. Streamlit AppTest에서는 키 없이 진단, 오답 힌트, 로그, 학습 코드 복원과 결과 지표를 확인했다.

실제 브라우저에서도 캡처에 사용한 Streamlit 서버를 종료하고 키 없이 새 서버를 시작한 뒤 같은 학습 코드로 복원했다. 이어 풀 문제, 다음 추천, 정답 8회, 오답 3회, 힌트 1회를 확인했다.

## 검증 범위

- 온라인 API 경로는 로컬 모의 서버에서 검증했다. 실제 OpenAI 제공자 호출은 실행하지 않았다.
- 기본 TF-IDF 검색을 실행했다. 별도 설치가 필요한 Sentence Transformers 의미 검색은 실행하지 않았다.
- 브라우저 실행 기록은 [캡처 안내](screenshots/README.md)를 참고한다.
