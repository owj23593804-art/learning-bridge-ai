# AI Agent 동작

1. 진단 종료, 정답, 첫 오답, 반복 오답 또는 힌트 요청 사건을 확인한다.
2. 사건에 맞는 허용 도구 목록을 모델에 제공한다. 모델은 중간 도구 응답을 읽고 후속 호출을 선택한다.
3. 함수 이름, 호출 ID, 빈 JSON 인수, 중복 호출 여부를 검증하고 등록된 Python 함수를 실행한다.
4. 반환값을 같은 호출 ID의 도구 메시지로 API에 보낸다. 로그에는 호출 사실과 공개 가능한 결과를 남긴다.
5. Pydantic으로 표현 유형과 근거 ID를 검사한다. 최종 응답 검증 실패 시 한 번 수정 요청한다. API 요청은 호출당 8초, 실행당 최대 6회다. 연결 또는 검증 실패 시 기본 정책이 필요한 도구를 고른다.
6. 고정된 검증 문제 힌트와 실제 검색 문서의 발췌문을 학생에게 제공한다. 온라인 모델은 표현 유형과 근거 발췌를 선택해 응답을 구성한다.

| 도구 | 반환 내용 |
|---|---|
| `diagnose_level` | 진단 진행, 개념별 정오답 수, 연속 실패 횟수 |
| `search_material` | 개념과 문항에 맞는 학습 자료 및 출처 |
| `generate_hint` | 문제은행의 검증된 단계 힌트 |
| `evaluate_answer` | 입력값의 결정적 채점 결과 |
| `update_learning_plan` | SQLite에 반영한 다음 학습 행동과 추천 개념 |

진도 정책은 채점 트랜잭션에서 적용한다. 진단 후 가장 낮은 개념으로 시작하고, 첫 오답은 힌트와 재도전, 같은 문제의 두 번째 오답은 선수 개념 연습으로 이어진다. 기초 개념에서 두 번 틀리면 다른 기초 문제를 제공한다. 정답을 맞히면 약한 개념을 우선하고, 모든 개념 비율이 80% 이상이면 다음 개념으로 순환한다.

진단 종료에는 진단과 계획 도구를 요구한다. 힌트 상황에서는 힌트 도구를 요구한다. 반복 오답에서는 선수 개념 검색이 가능하다. 모델은 추가 근거가 필요할 때 검색을 호출할 수 있다. API에는 문항과 학습 상태 요약을 보내며 학생 코드와 자유 입력값은 전송하지 않는다. 로그에 API 키, 원시 응답, 내부 추론은 기록하지 않는다.
